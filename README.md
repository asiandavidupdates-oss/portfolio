# Saad Qureshi — AI Creator & Video Editor Portfolio

A responsive, premium-dark portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `saad-qureshi-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step or framework is required.

## Before publishing — important
1. Replace the three sample project cards in `index.html` with real work or add your own project cards.
2. Add public social profile URLs in the `socialLinks` object at the top of `script.js`.
3. Add public project links (YouTube, Vimeo, Google Drive with public access, etc.) or put images/videos in `assets/projects/` and reference them from your project cards.
4. Test the website on mobile and desktop.

## About the Add Your Work panel
The panel is a quick browser preview tool. Files selected from your computer are **not uploaded to GitHub or a web server**; they only preview in the current browser session. The panel does not permanently publish projects. To make work visible to everyone, add the media files to this project folder and commit/push them to GitHub, or use public URLs.

For GitHub Pages, a simple approach is:
1. Create a public GitHub repository, for example `saad-qureshi-portfolio`.
2. Upload the contents of this folder (make sure `index.html` is in the repository root).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. Your public URL will appear in the Pages settings.
